# RewardLoop PWA — Phase 1

This is a phone-friendly prototype. It runs in a browser and can be installed to the Android home screen when hosted over HTTPS.

## Important
This version is demo-only:
- No real advertisements
- No real revenue
- No real cash payouts
- Demo points are stored in the browser's localStorage
- Do not use demo balances as real user balances

## Fastest phone test
You can test the UI by opening `index.html` in a browser/file viewer that allows local HTML. PWA install/offline service-worker behavior normally requires HTTPS hosting (or localhost).
